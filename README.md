# Loma Records — Retro / Modern Identity

This version is based on the **earlier modern website**, not the fully retro redesign. It keeps the oversized typography, strong grids and interactive motion while introducing a restrained vintage soul palette and the supplied PNG logo.

## Open
Open `html/index.html` in your browser or use VS Code Live Server.

## Folder guide
- `html/` — index, about, shows, shop (one HTML per page)
- `css/base.css` — shared typography, colors, header, footer, brand logo
- `css/index.css`, `about.css`, `shows.css`, `shop.css` — page-specific styles
- `js/main.js` — menu, reveal and interactions
- `images/loma-logo.png` — your supplied logo (replace here if needed)
- `media/` — your original motion videos

## Replace images
Place your photographs in `images/` and use `../images/filename.jpg` in the HTML files.

## Notes
Shows and merch entries are conceptual placeholders, not real booking or checkout. Social links point to the platform home pages until replaced.
