Place your own images in this folder.
Example: images/linda-jones.jpg, images/concert-01.jpg, images/merch-shirt.jpg.
To replace an artist placeholder in artists.html, change:
<div class="image-slot image-slot-one">...</div>
to:
<div class="image-slot image-slot-one" style="background-image:url('images/linda-jones.jpg');background-size:cover;background-position:center">...</div>
The CSS files are separate for each page.
